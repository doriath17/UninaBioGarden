### Presentation

These python scripts will be useful to populate the database.

### Setup

1. Create a virtual environment with `python3 -m venv .venv`
2. Activate the environment in the terminal with `source ./.venv/bin/activate`.
   In VSCode this can also be achieved by opening the palette (`ctrl + shift + p`), searching for `python: select interpreter` and choosing the one corresponding to `.venv`.

3. Installing the dependecies:

- `pip install psycopg` library to connect to `postgresql`.
- `pip install Faker` mock-data library.
